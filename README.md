**AI Business Risk & Verification Automation**
An AI-powered Python project that validates company information, analyzes potential business risk indicators, identifies information requiring verification, and generates business intelligence using AI.

**Features**
1. Company data validation from CSV
2. AI-powered risk analysis
3. Business information verification
4. Business intelligence analysis
5. AI-based processing decisions
6. JSON result storage

**AI Agents**
1. AI Analysis Agent — Overall company analysis
2. Verify Agent — Identifies information requiring verification
3. Risk Agent — Identifies potential risk indicators
4. Business Intelligence Agent — Generates business insights
5. Decision Agent — Determines the required processing action
   
**Technologies**
Python | OpenAI API | CSV | JSON | Requests

**Workflow**
CSV Data → Validation → AI Analysis → Verification
→ Risk Analysis → Business Intelligence → Decision
→ results.json

**Input** 
Company Name, Country, Industry, Website, Description

**Output** 
Processed company results are saved in results.json.

**Responsible AI** 

The system distinguishes between available information, missing data, and potential risk indicators and avoids unsupported accusations.
